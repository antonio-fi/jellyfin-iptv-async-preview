# Contributing

This is an experimental, community-maintained proof of concept; it is not an official Jellyfin component.

Please avoid uploading production IPTV playlists, stream URLs, credentials, tokens, screenshots with account identifiers, or personal device addresses. Before submitting changes, validate Python and JavaScript syntax and test with authorized streams in an isolated trusted network.

For architecture changes, explain how network I/O, decoding, cache updates and Jellyfin UI rendering remain independent. Avoid blocking the browser navigation or media playback path.
